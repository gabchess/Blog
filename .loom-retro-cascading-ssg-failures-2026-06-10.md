### Root Cause Analysis

vite-react-ssg has three structural problems:

1. **Module export bug**: The SSR build phase does not create or correctly name `main.mjs` in the temp directory. Either:
   - The plugin's code-generation step is broken
   - The filename hash algorithm is inconsistent between build phases
   - The module never gets written to disk

2. **No error recovery**: When SSR fails, the plugin doesn't catch the error and execute cleanup. Instead, it crashes, and cleanup runs as a separate uncaught error.

3. **Insufficient cleanup logic**: The cleanup phase uses `rmdir()` which fails on non-empty directories. Should use recursive `rm -rf` or iterate to remove contents first.
