## AR-381 Classification

**Primary Failure Class:** `source_amnesia`

vite-react-ssg has built the files successfully but has lost track of where they are (`dist/index.html` exists but tool cannot find it). This is not a fabricated path (confabulation), but a lost reference to a real file that the tool itself created.

**Secondary:** `locked_in`

The SSG tool knows it needs to render pages, has all the build artifacts, but cannot proceed due to file-not-found errors. The rendering logic is blocked mid-execution.

## Root Cause Hypothesis

Likely race condition or async ordering issue:

1. ✓ Client build writes `dist/` → `dist/index.html` created
2. ✓ Server build completes
3. ✓ SSR manifest copied to `dist/.vite/ssr-manifest.json`
4. ✗ Rendering phase attempts to read `dist/index.html`
   - File may not be fully flushed to disk
   - File descriptors may not be closed yet
   - Working directory may have changed unexpectedly
   - SSG temp directory state may interfere with path resolution
