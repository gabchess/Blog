## STOP: Deterministic Failure Detected

**Pattern:** Same exact error, same exact location, **5 consecutive builds**

```
Error: [vite-react-ssg] Error on page: /
TypeError: files.forEach is not a function
    at file:///.../vite-react-ssg.DsKK_1op.mjs:56:11
```

## Why This Matters

A deterministic, non-transient failure that repeats identically across 5+ runs is NOT a race condition, NOT a timing issue, and NOT fixed by retrying.

**This is a configuration or code problem that requires investigation, not iteration.**

## AR-381 Classification: `anosognosia`

Continuing to rebuild without fixing the root cause is the definition of anosognosia: "continuing to execute the same failing action expecting different results."

The build system does not recognize that it has a structural problem and keeps reporting "BUILD FAILED — fix errors before accepting completion" without providing the actual fix.

## Root Cause

The static loader for the home page route ("/") is returning a **non-array value** where vite-react-ssg expects an array.

In `vite-react-ssg.DsKK_1op.mjs:56`:
```javascript
// Expects: files is an Array<Asset>
// Actually receiving: files is null | undefined | object | string | number
files.forEach(...)  // TypeError
```
