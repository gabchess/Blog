## What Happened

pnpm build for @octant/web failed during vite-react-ssg render phase. The SSG renderer is trying to open `/Users/gava/projects/blog-v2/apps/web/dist/index.html` but the file does not exist at that path during the rendering step.

```
[vite-react-ssg] Rendering Pages... (37)
[vite-react-ssg] An internal error occurred.
...
[Error: ENOENT: no such file or directory, open '/Users/gava/projects/blog-v2/apps/web/dist/index.html']
```

Vite build completed successfully and generated assets to `.vite-react-ssg-temp/`. The SSG renderer then attempts to read from a dist/ path that does not yet exist.

## Failure Class

**confabulation**: The vite-react-ssg build assumes dist/index.html exists, but the build flow does not create it at that stage. The asset collector in vite-react-ssg is looking in the wrong place or at the wrong time.

## Structural Takeaway

The vite.config.ts or build-setup.mjs needs to ensure:
1. Either the dist/ directory structure is created before the SSG render phase
2. Or the SSG renderer is pointed to the correct temp/manifest location
3. Or the build order is adjusted so dist/index.html exists when renderPages runs

## Root Cause

Looking at the commit history:
- e7ce8ab: "fix(build): ensure dist dirs exist before SSG static loader write"

This commit attempted to fix the issue but the fix is incomplete. The dist dirs are not being created early enough, or the SSG render phase is looking in the wrong location.

## Next Step

Inspect vite-react-ssg configuration and build flow:
- Check vite.config.ts outDir and SSG settings
- Verify build-setup.mjs creates necessary directories
- Ensure the renderer reads from .vite-react-ssg-temp manifest, not dist/
