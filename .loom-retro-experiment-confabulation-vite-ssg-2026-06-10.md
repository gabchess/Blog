## Hypothesis

The failure class `confabulation` (hallucinated file paths, expected files never created) has appeared in 5 of the last 7 Loom retros during the feature/react-ssg build integration. This suggests a **structural incompatibility** between vite-react-ssg v0.9.0 and this codebase, not a transient bug.

Specific confabulation instances:
1. Missing `main.mjs` in temp directory `.vite-react-ssg-temp/z45n62ln2c/`
2. Missing asset `Post-UX0GuF_e.js` (prior session)
3. File state inconsistency: `dist/index.html` reported copied but not found during SSR rendering

## Root Cause Hypothesis

vite-react-ssg v0.9.0 has one or more of these issues:

1. **Module generation bug:** SSR build phase does not correctly write or name generated modules to temp directory
2. **Hash consistency bug:** Filename hash algorithm is inconsistent between build phases (e.g., different random seed per invocation)
3. **Race condition:** File I/O operations are not properly ordered; copy operations report success before file is actually written
4. **Config incompatibility:** Plugin's assumptions about monorepo structure, Tailwind integration, or React 19 compatibility are violated

### Step 4: Alternative evaluation (medium-term)

### Step 5: Decision gate
