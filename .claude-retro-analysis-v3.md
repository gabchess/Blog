## AR-381 Classification

**Primary:** `confabulation`  
vite-react-ssg is receiving data it doesn't expect and attempting an operation (`.forEach()`) on a non-array type. The tool has fabricated an assumption about the data structure.

**Secondary:** `anosognosia`  
The build system reports success (`✓ built in 964ms`) but does not verify that the downstream consumer (vite-react-ssg rendering) can actually use the built artifacts. The SSG tool fails without detecting its own preconditions.

## Root Cause Hypothesis

**The `build-setup.mjs` script is likely breaking the static loader contract.**

vite-react-ssg expects static loaders to export loader functions that return an array of files (or null/Promise<Array>). The static loader for the home page ("/") is returning something else:

Possible issues:
1. `build-setup.mjs` modifies vite config in a way that breaks loader data structure
2. Static loader is returning a single object instead of an array
3. Static loader is returning `null` or `undefined` instead of an array
4. The SSG configuration expects a specific loader interface that `build-setup.mjs` changed
