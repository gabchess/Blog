## Failure Analysis

**Failure class: confabulation**

The vite-react-ssg build system assumes dist/index.html exists when the rendering phase runs. However:
1. `ensureDistDirs()` hook runs at buildStart — creates directory structure only
2. `copySsrManifest()` hook runs at writeBundle — copies index.html AFTER vite finishes
3. vite-react-ssg's renderPages phase runs DURING the build lifecycle, between steps 1 and 2
4. Result: renderer looks for file that hasn't been copied yet — confabulation of expected state

## Structural Takeaway

The build pipeline confuses the execution order of Vite hook lifecycle phases. The fix requires:
- Option A: Copy index.html earlier in the lifecycle (use a hook that fires before renderPages)
- Option B: Have the renderer read from src/index.html directly instead of expecting dist/index.html
- Option C: Pre-copy index.html in build-setup.mjs (already creates dist dirs; add file copy there)
